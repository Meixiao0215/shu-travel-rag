# 评测说明与本次结果

测试环境：Python 3.12、本地 BGE-M3、LangChain 1.4.0。完整版本见根目录 `requirements.lock`。

语料为上大内〔2026〕128号 PDF。40道人工种子题按30道开发题、10道留出题划分。本次仅运行开发集；其中27道是有标注证据的可回答单轮题，其他3道用于追问/拒绝编造/范围限制的生成评测。

这里能支持的结论：在这27题上，混合检索与向量检索都找齐了人工标注证据；混合检索的首个相关条款平均排名更靠前。不能据此声称混合检索普遍优于向量检索，也不能声称回答准确率达到100%。

## 一个失败案例

Q17：“差旅费报销需要哪些基本材料？”

BM25 前5条没有召回第十八条，而是返回了第二十五条、附表1、第二十六条、第二十七条、第四条。这些文本与报销材料有词项重叠，但没有完整覆盖基本报销要求。向量与混合检索均召回了第十八条。

这个案例适合面试解释：检索词面相关不等于证据充分；父条款回收可以保留完整内容，但无法补救完全未命中的父条款。

## 人工评阅量表

对生成答案逐题记录：

1. 结论是否回答了问题，是否误用人员等级或经费类型。
2. 每项结论是否由引用原文直接支撑，引用是否覆盖必要条件。
3. 是否遗漏例外，如会议统一安排、当日往返、横纵向项目差异。
4. 缺条件时是否询问必要条件，有答案时是否过度追问。
5. 文件未覆盖的问题是否明确说明范围限制。

将判断与原文依据一起保存，不只记录一个总分。
